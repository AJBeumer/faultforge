### Result
`npm run private:where` prints the absolute path of the private folder the harness will use, so the owner can confirm it before a run.

### Done when
- [ ] New script `packages/harness/src/private-where.ts`, `private:where` in `package.json`, prints the resolved path and exits 0; exits 2 if the folder does not exist.
- [ ] It resolves the folder exactly as `inject.ts` does, so the two can never disagree: `FAULTFORGE_PRIVATE_DIR` when set, otherwise `<repo>/private`.
- [ ] Unit tests cover the default, the override, and a missing folder.

### Why
Two runs this week used a scratch worktree, and it was not obvious which private folder the scripts would read.

### Notes
- `inject.ts` resolves the folder itself at the top of the file: `const PRIVATE_DIR = resolve(process.env.FAULTFORGE_PRIVATE_DIR ?? join(ROOT, "private"))`. Copy that line into the new script so both agree.
- Print the path only; never list the folder's contents.
