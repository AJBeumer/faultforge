### Result
A side note after "None." in a ticket's Depends on section no longer blocks the ticket. Only the first line of the section is read as the dependency list.

### Done when
- [ ] `writtenDependencies()` in `packages/harness/src/ticket-ready.ts` reads only the first non-empty line of the Depends on section when it matches `#N` numbers; a following line such as "(#108 may later move this)" is ignored.
- [ ] A ticket whose Depends on says "None." followed by a note that mentions an open ticket is reported ready.
- [ ] `packages/harness/src/ticket-ready.test.ts` gains cases beside "reads blockers written in Depends on": first line only, note after None, note before the list.

### Why
On 11 November the factory refused ticket #4 as "blocked by open tickets #108" because the Depends on section said "None." and then mentioned #108 in a parenthesis.

### Notes
- `writtenDependencies()` matches `#N` with a regex over the whole section text. The required section names come from `factory.json` through `loadFactory()` in `packages/harness/src/factory-config.ts`.
- The existing test "reads blockers written in Depends on" in `ticket-ready.test.ts` shows the input shape.
